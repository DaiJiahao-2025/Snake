# 模块：像素主题

## 目标
- 统一三页视觉语言：字体、配色、面板与按钮组件、阴影与边框
- 适配手机与横屏：布局折叠、触控友好、字号与间距自适应

## 实施策略
- 新增共享样式：`assets/pixel-theme.css`
- 页面仅保留少量页面级样式，其余由主题统一管理
- 优先不改动游戏逻辑，仅改样式与必要的结构类名

## 当前实现要点
- **字体**：Google Fonts `Noto Sans SC`（中文可读性）+ `Press Start 2P`（像素氛围），并提供系统字体回退
- **组件**：像素描边卡片/面板、按压反馈按钮、统一输入框风格
- **适配**：移动端断点下三栏折叠；画布尺寸按可用高度约束以适配横屏
