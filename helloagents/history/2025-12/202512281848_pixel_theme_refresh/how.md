# 技术设计: 精细像素风视觉升级（Stardew-like）

## 技术方案
### 核心技术
- CSS 变量（主题配色/尺寸/阴影）
- Google Fonts（像素风字体）+ 回退字体
- 响应式布局：`@media` 断点 + `prefers-reduced-motion`

### 实现要点
- 新增共享主题文件：`assets/pixel-theme.css`
  - 全局：背景（柔和渐变 + 像素格纹理）、字体栈、色板
  - 组件：面板（像素描边/内阴影）、按钮（像素边框/按压反馈）、输入/选择器
  - 画布：`image-rendering: pixelated;` 与清晰边框
- 页面改造策略
  - `Snake.html`：保留逻辑与主要 DOM 结构，补充类名/容器以便主题接管样式；移动端将左右栏折叠为上下区域
  - `Store.html`/`lottery.html`：替换为主题卡片布局，按钮与信息块与游戏页面一致

## 架构决策 ADR
### ADR-001: 共享主题文件优先
- **决策**：新增 `assets/pixel-theme.css`，三页引用同一主题
- **理由**：避免样式分叉，降低后续维护成本
- **替代方案**：三页各自内联样式（维护成本高，难保持一致）

## 安全与性能
- 仅引入字体资源，不引入第三方脚本
- CSS 轻量化，避免影响游戏帧率

## 测试与验收
- 手工验证三页：布局、按钮反馈、可读性
- 重点验证：移动端竖屏/横屏；设置面板可用；存档键兼容
